# Instrução de início — Claude Code

Ao iniciar uma sessão na Base Pedagógica:
1. Leia o `CLAUDE.md`.
2. Consulte o checklist mestre vigente: `docs/base-pedagogica/checklist.md`.
3. Verifique branch (`base-pedagogica`), HEAD e `git status`; não sobrescreva alterações locais e não troque de branch sem avisar.
4. Entenda a solicitação atual.
5. Investigue apenas o contexto necessário para executá-la.

Auditorias, inventários e suítes completas de testes só quando houver necessidade concreta (mudança relevante, indício de regressão ou pedido do usuário). A conferência de transição já foi cumprida (`04_CHECKLIST_DE_CONTINUIDADE.md`, registro histórico).
