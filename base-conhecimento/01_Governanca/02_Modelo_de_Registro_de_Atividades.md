# 02 --- Modelo de registro de atividades

Use este modelo para cada atividade ou conjunto de exercícios. Um
documento pode conter várias atividades, mas cada uma deve ser
identificável.

-   **Versão/data:**
-   **Arquivo original:**
-   **Status:** recebido / inventariado / em consolidação / conferido /
    consolidado
-   **Direitos/uso:** pessoal / autorizado / restrito / a verificar

## Conteúdo original

Preservar instruções, enunciados, textos, alternativas e exemplos
conforme a fonte.

## Resposta do aluno

Registrar exatamente a resposta enviada, sem corrigir dentro deste
campo.

## Correção humana

Registrar literalmente a correção do professor, incluindo marcações,
comentários e justificativas disponíveis. Se não houver correção humana,
escrever "não fornecida"; nunca preencher por inferência.

## Análise independente

Registrar separadamente: - explicação gramatical ou lexical; - por que a
resposta é válida ou inválida; - alternativas naturais; - diferenças de
registro ou variante; - dúvidas que dependem de confirmação.

Identificar explicitamente que se trata de análise da IA.
